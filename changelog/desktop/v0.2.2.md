# Programma lilOS 0.2.2 — 3 novembre 2026

Tag `desktop/v0.2.2` nel repository lilos. Non è ancora una release con gli installer: arriva con la prossima «pubblica release» (`release-vX.Y.Z`).

## Programma lilOS 0.2.1 → 0.2.2

- **Correzione bug — aggiornamenti del programma.** Il repository `GexyLab/lilos` è diventato privato: le sue release non si scaricano più senza accesso (`latest.yml` risponde 404), quindi il programma non trovava gli aggiornamenti e la pagina della release dava 404. Ora il programma cerca gli aggiornamenti in `https://github.com/GexyLab/lilos-plugins-official/releases/latest/download`, il repository ufficiale, che è pubblico. *Perché:* chi non ha accesso a lilos deve poter scaricare e aggiornare il programma.
- **Manutenzione — workflow.** `.github/workflows/lilos-desktop.yml` crea la release «lilOS X.Y.Z» nel repository ufficiale con il secret `RELEASES_TOKEN` (token *fine-grained*, Contents: read and write su `lilos-plugins-official`). Senza il secret il job `release` si ferma con un messaggio chiaro. *Perché:* `github.token` può scrivere solo nel repository del workflow ([D76](../../doc/interna/decisioni.md#d76-gli-installer-del-programma-stanno-nelle-release-del-repository-ufficiale)).

## Da sapere

- **I programmi già installati (0.1.1 e 0.2.0, cioè lilOS fino alla 1.24.0) non si aggiornano da soli**: cercano ancora nelle release di lilos, ora private. Vanno reinstallati a mano una volta dal nuovo installatore; lilOS, i dati e le impostazioni restano.
