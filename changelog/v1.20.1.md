# v1.20.1 — 2 novembre 2026

## lilOS 1.20.0 → 1.20.1 (kernel)

Nessun nuovo requisito.

- **Correzione bug — comandi dei moduli dalla riga di comando.** `npm run kernel:cli -- users-basic add <nome> --admin` (e ogni altro comando dei moduli, come `list`, `passwd`, `remove`) si fermava subito con l'errore «The "path" argument must be of type string». Il comando avviava i moduli senza la cartella dei loro dati (`modules-data`), che il kernel invece passa sempre. Ora la cartella è definita in un punto solo e la usano sia il kernel sia il comando. *Perché:* senza questo comando non si può creare il primo amministratore né cambiare una password a mano quando non si riesce ad accedere. lilOS in uso non cambia: la correzione riguarda solo il comando.

## Come aggiornare

AppStore → **Aggiornamenti** → aggiorna **lilOS**. Non serve altro.
