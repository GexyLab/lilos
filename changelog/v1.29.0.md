# v1.29.0 — 3 novembre 2026

## lilOS 1.28.0 → 1.29.0 (kernel e strumenti di sviluppo)

- **Manutenzione — il lilOS di sviluppo si prova con le app di `development`.** Una copia del repository di lilOS legge le app e i moduli da un repository locale (`apps.devRepository`), costruito da `plugins/` con `npm run dev:update`, invece che dal repository ufficiale. Così le modifiche si provano prima di pubblicarle. `npm run dev:start` aggiorna la copia e avvia kernel e pagina; il kernel di sviluppo ascolta sulla porta 8791, accanto a un lilOS installato sulla 8790. *Perché:* una modifica a un'app non si poteva provare senza pubblicarla (D81).

## Da sapere

- **Per chi ha lilOS installato non cambia niente:** `apps.devRepository` vale solo in una copia di sviluppo, e la release continua a scrivere la porta 8790 nella configurazione.
