# v1.33.0 — 5 novembre 2026

## lilOS 1.32.0 → 1.33.0 (pagina e kernel), SDK 0.20.0 → 0.21.0

- **Nuova funzionalità — file fino a 1 GB.** Il limite di 10 MB per file non c'è più: il kernel salva i file a flusso, senza tenerli in memoria, e il predefinito è 1 GB. Un amministratore lo cambia in Pannello di controllo → Archiviazione → Limiti; con 0 non c'è limite. *Perché:* video, archivi e immagini disco non entravano in lilOS (D85).
- **Nuova funzionalità — quota di spazio per utente.** Una quota predefinita per tutti (0 = senza limite, come prima) e una quota personale per singoli utenti, in Archiviazione → Utenti. Contano tutti i file della home, cestino compreso. Quando la quota è superata si rifiutano solo le scritture che fanno crescere lo spazio: cancellare, svuotare il cestino o rimpicciolire un file si può sempre, e lilOS salva sempre le proprie impostazioni. Al 90% arriva una notifica, che apre Archiviazione. *Perché:* con file grandi un utente poteva riempire il server.
- **Nuova funzionalità — Il mio spazio.** Ogni utente vede in Archiviazione quanto spazio usa, la sua quota e la dimensione massima di un file.
- **Nuova funzionalità — caricamenti a pezzi riprendibili.** I file più grandi di 8 MB vanno dal browser al kernel in più richieste; un invio interrotto dalla rete riparte dal punto in cui era arrivato. La dimensione dei pezzi si cambia in Limiti (utile se davanti a lilOS c'è un proxy che limita le richieste; 0 = una richiesta sola).
- **Miglioramento — soglie configurabili.** Lettura di un file intero in memoria (256 MB), testo (10 MB), file piccoli tenuti in una riga del database (1 MB), dimensione dei pezzi nel database (1 MB) e copia dei file nel browser (fino a 10 MB: i file più grandi non riempiono più il browser). Ogni valore mostra se è quello predefinito o è stato modificato, e si ripristina con un clic.
- **Miglioramento — impostazioni del kernel in un catalogo unico.** Le nuove impostazioni hanno valori predefiniti, si possono dare all'installazione (`lilos-install.json` → `kernel.settings`) e stanno nella configurazione del kernel (`config.json` → `settings`). È la base per gestirle in futuro da un sistema centrale con un modulo (vedi design/limiti-file.html, sezione 6: da confermare).
- **SDK 0.21.0.** Nuovo `kernelSettings` (`limits()`, `list()`, `update()`, `users()`, evento `change`) e `DEFAULT_FILE_LIMITS`; il salvataggio dei contenuti carica a pezzi i file grandi e tiene la copia locale solo fino a `files.cacheMax`. Per i moduli del kernel: `ctx.settings` e il metodo facoltativo `fs.usage()`; nuovo codice d'errore `quota` (HTTP 507).

## Altri componenti

- **Pannello di controllo 1.21.0 → 1.22.0** — *Nuova funzionalità:* Archiviazione con le sotto-schede Il mio spazio, Limiti e Utenti (le ultime due solo per gli amministratori). Richiede lilOS 1.33.0 per le nuove sotto-schede; con un lilOS più vecchio la scheda resta com'era.
- **Modulo fs-postgres 1.1.1 → 1.2.0** — *Nuova funzionalità:* segue le impostazioni del kernel per i pezzi e la lettura in memoria, e dice al kernel lo spazio usato da ogni utente (serve per le quote). *Miglioramento:* i file piccoli restano in una riga sola, quelli grandi vanno in pezzi anche quando arrivano interi. La dimensione dei pezzi si salva con ogni file, quindi cambiarla non tocca i file già scritti. Con un kernel più vecchio valgono i valori di prima. Senza questo aggiornamento lilOS 1.33.0 funziona, ma senza quote.
- **Moduli di rete** — *Miglioramento:* le soglie dei caricamenti diventano impostazioni del modulo: netfs-s3 1.1.0 → 1.2.0 (invio unico e dimensione delle parti), netfs-azblob 1.1.0 → 1.2.0 (invio unico e dimensione dei blocchi), netfs-google 1.0.0 → 1.1.0 (pezzi di caricamento su Drive), netfs-onedrive 1.2.0 → 1.3.0 (pezzi di caricamento), netfs-nfs 1.1.0 → 1.2.0 (byte per lettura e scrittura). I predefiniti sono quelli di prima.
- **Pacchetti di lingua 1.0.0 → 1.1.0 (tutte le 20 lingue)** — *Miglioramento:* i nuovi messaggi del kernel (limiti, quote, caricamenti, impostazioni) tradotti. Richiedono lilOS 1.33.0.

## Da sapere

- Per aggiornare: AppStore → aggiorna prima lilOS, poi il modulo fs-postgres (serve un riavvio del kernel, che l'AppStore propone), il Pannello di controllo e la tua lingua.
- Chi aveva lilOS dietro un proxy (nginx, Apache) con un limite sulla dimensione delle richieste: lilOS manda pezzi da 8 MB. Alza il limite del proxy, oppure abbassa «Pezzi di caricamento» in Limiti.
- Le app che leggono un file tutto in memoria hanno i loro limiti (Foto 25 MB, anteprime 20 MB, Compress Archive 256 MB in tutto): per i file più grandi lo dicono loro.
