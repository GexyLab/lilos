# v1.31.0 — 4 novembre 2026

## lilOS 1.30.0 → 1.31.0 (pagina e kernel), SDK 0.18.0 → 0.19.0

- **Nuova funzionalità — widget sulla scrivania.** Un'app di sistema può mostrare sulla scrivania i file di un suo tipo con un proprio widget, al posto dell'icona: la prima è Note adesive, i cui file `.sticky` diventano foglietti colorati da scrivere lì sopra. Il widget si seleziona, si sposta, va nelle workarea e nel Cestino come le icone; aprirlo lo modifica sul posto; «Riordina icone» lo lascia dov'è; nella minimappa ha il suo colore. Se l'app non c'è (o si sceglie un'altra app per quel tipo di file) i file tornano icone. *Perché:* chiesto dall'utente (note adesive sulla scrivania); i widget erano accettati nel manifesto ma non si vedevano (D83).
- **Nuova funzionalità — Nuovo → Nota adesiva.** Nel tasto destro della scrivania, quando Note adesive è installata. Chi ha già personalizzato quel menu la ritrova ripristinandolo (Pannello di controllo → Usabilità → Menu contestuale).
- **Compatibilità — manifesto.** `contributes.widgets[].fileType` (uno dei `fileTypes` dell'app, uno per widget); il permesso `desktop.widget` ora ha effetto per le app di sistema.
- **SDK 0.19.0 (compatibile).** `fs.everywhere(test)` elenca i nodi di tutti i workspace in sola lettura, `fs.bring(id, cartella)` porta un nodo da un altro workspace; le azioni di `menus` possono avere `visible`; nuovo glifo `note`. In `@lilos/system`: `revealOnDesk`, `bringToDesk`, `newWidgetOnDesk`, `widgetFor`.

## Da sapere

- Note adesive 1.0.0 è nel repository ufficiale e richiede lilOS ≥ 1.31.0: aggiorna prima lilOS, poi installala dall'AppStore.
