# v1.41.0 — 11 novembre 2026

Pubblicata nel repository ufficiale v1.71.0.

I blocchi di Logic Studio hanno nomi che richiamano le funzioni equivalenti dei linguaggi di programmazione (If · Else, Switch · Case, Intervallo (setInterval), Print (console.log), Push · Unshift, readFile, HTTP (fetch)…). Il blocco «Valore» diventa **Costante · Variabile**: di serie è una costante, con l'ingresso **imposta** collegato diventa una variabile.

## lilOS 1.40.0 → 1.41.0 (SDK 0.25.0 → 0.26.0)

- **Nuova funzionalità — porte nascoste di serie.** La definizione di un blocco o di una componente di Logic Studio può dire che una porta parte nascosta (`hidden: true`); l'utente la mostra con l'occhio nelle Proprietà. Serve agli ingressi che si usano di rado, come **invia** e **imposta** di Costante · Variabile.
- **Per gli sviluppatori.** `portsOf` dà anche `hiddenByDefault`; `portHidden(item, lato, porta, diSerie)` e `LogicSchema.setPortHidden(id, lato, porta, nascosta, diSerie)` tengono conto del predefinito (nel file resta solo la scelta diversa).

## Logic Studio IDE 1.4.0 → 1.5.0 (richiede lilOS ≥ 1.41.0)

- **Miglioramento — porte nascoste di serie.** L'occhio delle Proprietà mostra e nasconde anche le porte che il blocco tiene nascoste di serie, e il file ricorda la scelta.
- **Miglioramento — testi e guida con i nuovi nomi dei blocchi** (in italiano e in inglese).

## Logic Studio Engine (`logicstudio-engine`) 1.1.0 → 1.2.0

- **Nuova funzionalità — `b.linked(porta)`.** Un blocco può sapere se a un suo ingresso è collegato qualcosa, e comportarsi diversamente quando un ingresso facoltativo non è usato.
- **Documentazione.** Le porte `hidden: true` e `b.linked` nella pagina per chi scrive pacchetti; nuovi nomi dei blocchi in tutte le pagine.

## Blocchi di base (`logicstudio-core`) 1.1.0 → 1.2.0 (richiede il motore ≥ 1.2.0)

- **Compatibilità — «Valore» diventa «Costante · Variabile» (versione 2 del blocco).** Ha due ingressi nascosti di serie, che si mostrano con l'occhio:
  - **invia**: se non è collegato, il valore esce all'avvio dello schema; se è collegato, esce solo a ogni impulso;
  - **imposta**: se è collegato il blocco è una **variabile** (il valore che arriva, convertito nel Tipo, prende il posto di quello attuale); altrimenti è una **costante**.
  
  L'impostazione «Invia all'avvio» non c'è più: gli schemi salvati si aggiornano da soli. **Cosa cambia negli schemi esistenti:** un «Valore» con **invia** collegato e «Invia all'avvio» acceso non manda più il valore all'avvio; uno con «Invia all'avvio» spento e niente collegato a **invia** ora lo manda. Perché: un'impostazione in meno da ricordare, e lo stesso blocco serve da costante e da variabile.
- **Miglioramento — nomi della programmazione.** Per esempio: E/O/NON → AND/OR/NOT, Se → If · Else, Casi → Switch · Case, Ogni… → Intervallo (setInterval), Aspetta → Ritardo (setTimeout), Antirimbalzo → Debounce, Scrivi in console → Print (console.log), Leggi da console → Input (readline), Ingresso/Uscita di schema → Parametro/Return. Perché: chi conosce un linguaggio di programmazione riconosce subito cosa fa un blocco. Gli id dei blocchi non cambiano: gli schemi salvati restano validi.

## Liste e matrici (`logicstudio-collections`) 1.1.0 → 1.2.0

- **Miglioramento — nomi della programmazione.** Per esempio: Aggiungi elemento → Push · Unshift, Porzione → Slice, Contiene · Posizione → Includes · IndexOf, Unici → Distinct, Estrai campo → Map campo, Matrice da lista → Reshape, Appiattisci → Flatten.

- **Miglioramento — nomi della programmazione.** Notifica → Notify, Leggi/Scrivi/Aggiungi a file → readFile/writeFile/appendFile, Elenca cartella → readdir, Esiste → exists, Evento a lilOS → Emit.

## Rete (`logicstudio-net`) 1.1.0 → 1.2.0

- **Miglioramento — nomi della programmazione.** Richiesta web → HTTP (fetch).

## Componenti UI standard (`logicstudio-ui`) e Grafici (`logicstudio-charts`) 1.1.0 → 1.1.1

- **Documentazione.** Le pagine usano i nuovi nomi dei blocchi. Nessun cambiamento nel comportamento.

## Come aggiornare

1. AppStore → aggiorna **lilOS** (1.41.0).
2. AppStore → scheda **Kernel**: aggiorna **Logic Studio Engine** e i pacchetti di Logic Studio installati; il kernel li riavvia.
3. AppStore → aggiorna **Logic Studio IDE** (1.5.0).

Prima di aggiornare un programma attivo, controlla i blocchi «Valore» che avevano **invia** collegato e «Invia all'avvio» acceso: dopo l'aggiornamento non mandano più il valore all'avvio (per riaverlo, collega anche un blocco **All'avvio (main)** a **invia**).
