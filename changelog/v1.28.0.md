# v1.28.0 — 3 novembre 2026

## lilOS 1.27.0 → 1.28.0 (pagina)

- **Nuova funzionalità — «Mostra sul desktop» nel menu applicazioni.** Con il tasto destro su un'app del menu applicazioni (preferite, recenti, categorie, risultati della ricerca) c'è **Mostra sul desktop**: rimette l'icona dell'app sul desktop del workspace in cui sei. Per il File Manager riaccende l'elemento fisso della scrivania. Se l'icona c'è già, la voce è **Già sul desktop** e non si può scegliere. *Perché:* un'app tolta dal desktop non si poteva più rimettere.
