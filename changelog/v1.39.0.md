# v1.39.0 — 11 novembre 2026

Pubblicata nel repository ufficiale v1.68.0.

In Logic Studio le porte dei blocchi che non usi si possono nascondere, con l'occhio nella barra Proprietà; l'uscita Eccezione parte nascosta.

## lilOS 1.38.2 → 1.39.0 (SDK 0.23.2 → 0.24.0)

- **Nuova funzionalità — porte nascoste nei blocchi di Logic Studio.** Il disegno degli schemi non mostra le porte nascoste; una porta collegata compare sempre. L'uscita Eccezione parte nascosta: gli schemi già salvati con l'Eccezione collegata la mostrano come prima. Serve a Logic Studio IDE 1.2.1.
- **Per gli sviluppatori.** Nuovo export `portHidden`, nuovo metodo `LogicSchema.setPortHidden` (una porta collegata non si nasconde: restituisce `false`), `portsOf` dà anche `hidden`, `LogicSchema.parse` tiene `hide` dei blocchi. `LogicCanvas` ridisegna un blocco quando cambiano i suoi collegamenti (prima il pallino «collegata» poteva restare indietro).

## Logic Studio IDE 1.1.0 → 1.2.1 (richiede lilOS ≥ 1.39.0)

- **Nuova funzionalità — l'occhio accanto alle porte.** Nella barra **Proprietà** di un blocco, accanto a ogni porta c'è un occhio: la nasconde nel disegno (occhio barrato) o la mostra di nuovo. Serve a tenere puliti i blocchi con porte che non usi. Cambia solo il disegno: il programma funziona come prima e un ingresso nascosto tiene il suo valore all'avvio. Si annulla con Ctrl Z.
- **Nuova funzionalità — porte collegate sempre visibili.** Una porta collegata non si nasconde: il suo occhio è spento e il suggerimento spiega perché. Per nasconderla togli prima il collegamento.
- **Miglioramento — l'Eccezione nascosta di default.** L'uscita Eccezione di ogni blocco parte nascosta, perché quasi sempre non si collega (l'errore va comunque nella console principale). Per collegarla, premi prima il suo occhio.
- **Compatibilità.** La 1.2.0 non è stata pubblicata: la 1.2.1 è la stessa con il requisito corretto di lilOS 1.39.0, che porta le funzioni dell'SDK usate dall'occhio.

## Come aggiornare

1. AppStore → aggiorna **lilOS** (1.39.0).
2. AppStore → aggiorna **Logic Studio IDE** (1.2.1).
