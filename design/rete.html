1 · La connessione è una cartella: Home → Rete

Ogni connessione è montata in ~/Rete/<nome> e si apre come qualsiasi cartella: stessi comandi, trascinamento, copia/incolla, apertura con le app. Nella barra laterale c'è la sezione Rete con lo stato di ogni connessione (verde connessa, grigia scollegata, blu con trasferimenti in corso). Trascinando file dalla Home dentro la cartella remota parte un trasferimento nel kernel.

2 · Connetti a un server (SFTP)

Una sola finestra per tutti i protocolli: il protocollo si sceglie da un elenco a tendina (resta chiaro anche quando i protocolli aumentano) e i campi della finestra cambiano con la scelta (porta di serie, condivisione e dominio per SMB, FTPS esplicito/implicito, chiave SSH per SFTP, URL per WebDAV). La password resta nel kernel, cifrata, e la pagina non la riceve mai indietro. Alla prima connessione SFTP lilOS chiede di confermare l'impronta del server; FTPS e WebDAV con certificato non valido chiedono conferma allo stesso modo.

2b · Connetti a un server (SMB)

Per SMB servono anche la condivisione (con «Elenca» per sceglierla tra quelle del server) e il dominio o gruppo di lavoro; si può entrare come ospite. Solo SMB 2 e 3: il vecchio SMB1/CIFS non è supportato, perché non è sicuro e Windows lo tiene spento di serie. Se il server parla solo SMB1 lo dice l'errore.

3 · Trasferimento dati (File Manager già chiuso)

Si apre da sola se un trasferimento dura più di 5 secondi. È una finestra di lilOS, non del File Manager: il lavoro gira nel kernel, quindi continua anche chiudendo il File Manager (e anche chiudendo la pagina o uscendo). Chiudere questa finestra la nasconde e basta; si riapre dall'icona nella barra. Si ferma solo con Annulla: tutto, una destinazione, una cartella o un singolo file. In alto i totali di dati inviati e ricevuti; per ogni destinazione il file in corso e la coda. I file aggiunti alla stessa destinazione finiscono in fondo alla sua coda (evidenziati).

4 · Finestra chiusa: icona nella barra, poi la notifica

Mentre ci sono trasferimenti, nella barra c'è un'icona con l'anello di avanzamento; passandoci sopra si vede il riepilogo, un clic riapre la finestra. Alla fine arriva una notifica (niente toast, come da D52) con gli eventuali errori; il clic riapre la finestra con l'elenco di ciò che non è andato.
