# Italiano

Il pacchetto di lingua italiano di lilOS: traduce i testi del sistema (scrivania, menu applicazioni, barra delle applicazioni, finestre di sistema, accesso e messaggi del kernel).

Le app hanno le proprie traduzioni: ognuna usa l'italiano se lo ha, altrimenti l'inglese.

Dopo averlo installato scegli **Italiano** in Pannello di controllo → Lingua. Lo può installare qualsiasi utente ed è disponibile per tutti; lo rimuove chi l'ha installato o un amministratore.
