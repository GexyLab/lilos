# Bahasa Indonesia

Paket bahasa Indonesia untuk lilOS: menerjemahkan teks sistem (desktop, menu aplikasi, bilah tugas, jendela sistem, proses masuk, dan pesan kernel).

Aplikasi memiliki terjemahannya sendiri: masing-masing menggunakan bahasa Indonesia jika tersedia, jika tidak menggunakan bahasa Inggris.

Setelah menginstalnya, pilih **Bahasa Indonesia** di Panel Kontrol → Bahasa. Paket ini dapat diinstal oleh pengguna mana pun dan tersedia untuk semua orang; paket ini dihapus oleh yang menginstalnya atau oleh administrator.
