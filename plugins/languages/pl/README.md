# Polski

Polski pakiet językowy lilOS: tłumaczy teksty systemu (pulpit, menu aplikacji, pasek zadań, okna systemowe, logowanie i komunikaty kernela).

Aplikacje mają własne tłumaczenia: każda używa języka polskiego, jeśli go ma, w przeciwnym razie angielskiego.

Po zainstalowaniu wybierz **Polski** w Panelu sterowania → Język. Może go zainstalować każdy użytkownik i jest dostępny dla wszystkich; usuwa go osoba, która go zainstalowała, lub administrator.
