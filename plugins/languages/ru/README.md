# Русский

Русский языковой пакет lilOS: переводит тексты системы (рабочий стол, меню приложений, панель задач, системные окна, вход и сообщения ядра).

У приложений есть собственные переводы: каждое использует русский, если он у него есть, иначе — английский.

После установки выберите **Русский** в разделе Панель управления → Язык. Установить его может любой пользователь, и он доступен всем; удалить его может тот, кто его установил, или администратор.
