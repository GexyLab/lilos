# Ελληνικά

Το ελληνικό πακέτο γλώσσας του lilOS: μεταφράζει τα κείμενα του συστήματος (επιφάνεια εργασίας, μενού εφαρμογών, γραμμή εργασιών, παράθυρα συστήματος, σύνδεση και μηνύματα του kernel).

Οι εφαρμογές έχουν τις δικές τους μεταφράσεις: η καθεμία χρησιμοποιεί τα Ελληνικά αν τα έχει, διαφορετικά τα Αγγλικά.

Μετά την εγκατάσταση επιλέξτε **Ελληνικά** στον Πίνακα Ελέγχου → Γλώσσα. Μπορεί να το εγκαταστήσει οποιοσδήποτε χρήστης και είναι διαθέσιμο για όλους· το καταργεί όποιος το εγκατέστησε ή ένας διαχειριστής.
