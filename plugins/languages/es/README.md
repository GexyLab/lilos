# Español

El paquete de idioma español de lilOS: traduce los textos del sistema (escritorio, menú de aplicaciones, barra de tareas, ventanas del sistema, inicio de sesión y mensajes del kernel).

Las apps tienen sus propias traducciones: cada una usa el español si lo tiene y, si no, el inglés.

Después de instalarlo, elige **Español** en Panel de control → Idioma. Cualquier usuario puede instalarlo y está disponible para todos; lo quita quien lo instaló o un administrador.
