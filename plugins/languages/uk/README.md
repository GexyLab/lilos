# Українська

Український мовний пакет lilOS: перекладає тексти системи (робочий стіл, меню застосунків, панель завдань, системні вікна, вхід і повідомлення ядра).

Застосунки мають власні переклади: кожен використовує українську, якщо вона в нього є, інакше — англійську.

Після встановлення виберіть **Українська** в розділі Панель керування → Мова. Встановити його може будь-який користувач, і він доступний усім; видалити його може той, хто його встановив, або адміністратор.
