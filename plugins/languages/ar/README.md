# العربية

حزمة اللغة العربية لـ lilOS: تترجم نصوص النظام (سطح المكتب، وقائمة التطبيقات، وشريط المهام، ونوافذ النظام، وتسجيل الدخول، ورسائل kernel).

للتطبيقات ترجماتها الخاصة: يستخدم كل تطبيق العربية إذا كانت متوفرة فيه، وإلا فالإنجليزية.

بعد تثبيتها اختر **العربية** في لوحة التحكم ← اللغة. يمكن لأي مستخدم تثبيتها وتصبح متاحة للجميع؛ ويزيلها من ثبّتها أو المسؤول.
