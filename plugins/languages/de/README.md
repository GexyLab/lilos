# Deutsch

Das deutsche Sprachpaket von lilOS: Es übersetzt die Texte des Systems (Schreibtisch, Anwendungsmenü, Taskleiste, Systemfenster, Anmeldung und Meldungen des Kernels).

Die Apps haben ihre eigenen Übersetzungen: Jede verwendet Deutsch, wenn sie es hat, sonst Englisch.

Wählen Sie nach der Installation **Deutsch** unter Systemsteuerung → Sprache. Jeder Benutzer kann es installieren, und es steht allen zur Verfügung; entfernen kann es, wer es installiert hat, oder ein Administrator.
