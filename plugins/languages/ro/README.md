# Română

Pachetul de limbă română al lilOS: traduce textele sistemului (desktop, meniul aplicațiilor, bara de activități, ferestrele de sistem, conectarea și mesajele kernelului).

Aplicațiile au propriile traduceri: fiecare folosește limba română dacă o are, altfel limba engleză.

După instalare, alegeți **Română** în Panou de control → Limbă. Orice utilizator îl poate instala și este disponibil pentru toți; îl elimină cel care l-a instalat sau un administrator.
