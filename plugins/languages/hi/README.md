# हिन्दी

lilOS का हिन्दी भाषा पैक: यह सिस्टम के टेक्स्ट का अनुवाद करता है (डेस्कटॉप, ऐप्लिकेशन मेनू, टास्कबार, सिस्टम विंडो, साइन-इन और कर्नेल के संदेश)।

ऐप के अपने अनुवाद होते हैं: हर ऐप हिन्दी का उपयोग करता है यदि उसमें हिन्दी है, अन्यथा अंग्रेज़ी का।

इसे इंस्टॉल करने के बाद नियंत्रण कक्ष → भाषा में **हिन्दी** चुनें। इसे कोई भी उपयोगकर्ता इंस्टॉल कर सकता है और यह सभी के लिए उपलब्ध होता है; इसे वही निकालता है जिसने इसे इंस्टॉल किया है, या कोई व्यवस्थापक।
