# اردو

lilOS کا اردو زبان پیک: یہ سسٹم کے متون کا ترجمہ کرتا ہے (ڈیسک ٹاپ، ایپس مینیو، ٹاسک بار، سسٹم ونڈوز، سائن ان اور kernel کے پیغامات)۔

ایپس کے اپنے ترجمے ہوتے ہیں: ہر ایپ اردو استعمال کرتی ہے اگر اس میں موجود ہو، ورنہ انگریزی۔

انسٹال کرنے کے بعد کنٹرول پینل ← زبان میں **اردو** منتخب کریں۔ اسے کوئی بھی صارف انسٹال کر سکتا ہے اور یہ سب کے لیے دستیاب ہوتا ہے؛ اسے وہی ہٹاتا ہے جس نے اسے انسٹال کیا یا کوئی منتظم۔
