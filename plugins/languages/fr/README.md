# Français

Le pack de langue français de lilOS : il traduit les textes du système (bureau, menu des applications, barre des tâches, fenêtres système, connexion et messages du kernel).

Les apps ont leurs propres traductions : chacune utilise le français si elle l’a, sinon l’anglais.

Une fois installé, choisissez **Français** dans Panneau de configuration → Langue. N’importe quel utilisateur peut l’installer et il est disponible pour tous ; il est supprimé par la personne qui l’a installé ou par un administrateur.
