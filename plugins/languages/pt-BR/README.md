# Português (Brasil)

O pacote de idioma português do Brasil do lilOS: traduz os textos do sistema (área de trabalho, menu de aplicativos, barra de tarefas, janelas do sistema, login e mensagens do kernel).

Os apps têm as próprias traduções: cada um usa o português do Brasil se o tiver; caso contrário, o inglês.

Depois de instalá-lo, escolha **Português (Brasil)** em Painel de controle → Idioma. Qualquer usuário pode instalá-lo e ele fica disponível para todos; quem o instalou ou um administrador pode removê-lo.
