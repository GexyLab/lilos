# logicstudio-core

I **blocchi di base** di Logic Studio: valori, logica (E, O, Confronta, Casi…), matematica, testo, oggetti e liste, tempo (Ogni…, Aspetta…), le due **console** (Scrivi in console, Leggi da console), le **porte di schema** (Ingresso e Uscita di schema, per collegare schemi diversi di un progetto) e l'oggetto delle **Componenti UI** in uno schema.

Alcuni blocchi permettono di aggiungere porte (per esempio E, Somma, Formatta testo, Casi): si aggiungono e si tolgono nella barra delle proprietà dell'IDE.

Richiede il motore `logicstudio-engine`.
