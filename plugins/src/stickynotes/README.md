# Note adesive

Foglietti colorati sulla scrivania, da scrivere lì sopra.

## Cosa fa

- **Una nota si crea** con il tasto destro sulla scrivania → **Nuovo → Nota adesiva**, oppure con **Nuova nota** nella finestra dell'app: compare dove hai fatto clic (o al centro della vista), pronta da scrivere.
- **Si scrive** con doppio clic o **Invio** sulla nota selezionata; **Esc**, **Fine** o un clic fuori smette e salva. La prima riga è il titolo. Una nota nuova lasciata vuota sparisce.
- **Elenchi**: `- ` per un elenco puntato, `- [ ] ` per una casella da spuntare (o i pulsanti nella barra sopra la nota). Le caselle si spuntano con un clic anche senza scrivere. `**testo**` è grassetto (**Ctrl B**).
- **Colore e misura**: sei colori nella barra o nel menu della nota; la misura si cambia trascinando l'angolo in basso a destra, o dal menu (Piccola, Media, Grande).
- **Promemoria**: la campanella propone tempi rapidi (tra un'ora, stasera, domani mattina, lunedì) o una data e un'ora. Arriva come notifica anche a lilOS chiuso; un clic mostra la nota.
- **Sulla scrivania** le note si selezionano, si spostano, entrano nelle workarea e vanno nel Cestino come le icone. Da lontano si vede solo il titolo, più grande, poi solo il foglietto colorato.
- **La finestra Note adesive** elenca tutte le note, di ogni workspace: si cerca nel testo, si filtra per workspace, colore o promemoria. **Mostra** porta alla nota, **Porta qui** la sposta al centro della vista.

## Le note sono file

Ogni nota è un file di testo `.sticky` nella cartella Scrivania: si vede nel File Manager (con l'anteprima), si apre con l'Editor, si copia e si cerca come gli altri file. Colore, misura e promemoria sono dati dell'app sul file.
