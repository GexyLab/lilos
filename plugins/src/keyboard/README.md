# Tastiera a schermo

Una tastiera per scrivere con il mouse o con un dito, nella finestra in cui stai scrivendo.

## Cosa fa

- **Scrive dove sei**: clicca nel campo in cui vuoi scrivere, poi premi i tasti. La finestra della tastiera non prende mai il focus: puoi cliccarla, spostarla o ridurla e il testo continua ad andare nella finestra di prima, che resta quella attiva. Funziona anche nelle app isolate.
- **Resta sopra** le altre finestre.
- **Due layout**: italiano e americano (EN). Il tasto **IT**/**EN** li alterna e la scelta resta salvata; la prima volta segue la lingua del sistema. La barra spaziatrice mostra il layout in uso.
- **Maiusc, Ctrl, Alt e AltGr**: un tocco vale per il tasto successivo; due tocchi di seguito lo bloccano (compare un pallino) finché non lo premi di nuovo. **Bloc Maiusc** cambia solo le lettere.
- Le etichette cambiano con i modificatori. In piccolo, come su una tastiera vera, il carattere con Maiusc (in alto a sinistra) e quello con AltGr (in basso a destra, colorato).
- Un tasto tenuto premuto si ripete.
- I tasti che premi sulla tastiera vera si illuminano anche qui.

## Caratteri con AltGr (layout italiano)

| Tasto | AltGr | AltGr + Maiusc |
| --- | --- | --- |
| e | € | |
| è | [ | { |
| + | ] | } |
| ò | @ | |
| à | # | |
| ' | ` | |
| ì | ~ | |

Nel layout americano il tasto Alt di destra è un secondo Alt.

## Tasti speciali

Esc, Tab, Invio, Backspace, Canc e le frecce fanno quello che fanno sulla tastiera vera: con Ctrl, Backspace e Canc cancellano una parola e le frecce si spostano di una parola; con Maiusc le frecce selezionano. Funzionano anche le scorciatoie, per esempio Ctrl+S, Ctrl+Z o Ctrl+A.

## Da sapere

- Serve una versione di lilOS che sappia mandare i tasti alle altre finestre: con una precedente la tastiera mostra un messaggio che chiede di aggiornare lilOS.
- Le app remote (un sito a sé) non ricevono i tasti.
- Nelle app isolate Ctrl+C, Ctrl+X e Ctrl+V possono non funzionare: il browser non permette di usare gli appunti da lì.
- Nei testi su più righe le frecce su e giù si spostano per righe di testo, non per le righe che vanno a capo da sole.
- È una finestra come le altre: si sposta e si rimpicciolisce con lo zoom della scrivania.
